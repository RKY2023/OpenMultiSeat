# Activation Dialog

> ASTER reference: https://dokwiki.ibiksoft.com/en/v3/core/gui/gui_activationdialog

## What ASTER does

The Activation dialog is where a purchaser registers an ASTER installation by entering a serial number, which requires internet access to validate and unlock the licensed number of workplaces. Once a Pro license is active, it also offers a button to start a 14-day trial of additional workplaces beyond the purchased limit. It additionally provides access to proxy settings (for activating through a proxy server) and to the Deactivation dialog for removing existing activations.

## OpenMultiSeat status

**➖ Not applicable** — OpenMultiSeat has no licensing or activation system at all. It is fully free and open source (MIT-licensed): there are no serial numbers, no trial periods, no per-seat purchase limits, and no activation servers to contact. Every seat OpenMultiSeat can enumerate hardware for, it can configure, with no separate unlock step. This is a deliberate, permanent product difference from ASTER, not a missing feature.
