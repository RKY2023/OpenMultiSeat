# "License Expire Time" Notification

> ASTER reference: https://dokwiki.ibiksoft.com/en/v3/core/gui/gui_expirationdialog

## What ASTER does

This notification window warns about subscription-based licenses (Trial or Temporary) that are about to expire, listing each one's type, number of workplaces, and expiration date. By default it starts appearing 15 days before the nearest expiration and then shows again every day until resolved; a "Next date alert" control lets the user push the next reminder back.

## OpenMultiSeat status

**➖ Not applicable** — OpenMultiSeat has no subscription or time-limited licenses to expire. Being free and open source with no activation system (see [Activation Dialog](activation-dialog.md)), there is no expiration state to track and therefore nothing for a notification like this one to report.
