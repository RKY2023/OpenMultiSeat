# Cleanup License

> ASTER reference: observed in the live ASTER v2.70.5 desktop app (Workplaces tab → hamburger menu → "Cleanup license") — not covered by the public wiki pages this doc set otherwise cites.

## What ASTER does

"Cleanup license" clears locally cached license/activation state for the current installation — used when troubleshooting activation problems or preparing to re-activate on a machine (e.g. after significant hardware changes ASTER's licensing ties itself to).

## OpenMultiSeat status

➖ **Not applicable** — OpenMultiSeat has no licensing or activation system of any kind; every seat is available with no per-seat license limit and no activation state to clean up. See [`../user-manual/licensing-model.md`](../user-manual/licensing-model.md).
