# Request for Automatic Activation

> ASTER reference: https://dokwiki.ibiksoft.com/en/v3/core/gui/gui_autoactquery

## What ASTER does

This dialog drives automatic activation from a master license: it asks the user to enter the ASTER license (and, if the master license was created with one, a password) to continue, then processes the activation when "Activate" is clicked, or aborts on "Cancel."

## OpenMultiSeat status

**➖ Not applicable** — OpenMultiSeat has no master-license or automatic-activation concept, because it has no licensing or activation system whatsoever. See [Activation Dialog](activation-dialog.md).
