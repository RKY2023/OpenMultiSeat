# Deactivation Dialog

> ASTER reference: https://dokwiki.ibiksoft.com/en/v3/core/gui/gui_deactivationdialog

## What ASTER does

The Deactivation dialog lets a licensee free up or transfer ASTER licenses from the current PC. It lists all activated licenses in a table (activation code, registration name, extension status, workplace count, expiration date, transfer history) with checkboxes to select which to deactivate, plus an email field for status notifications, a reason dropdown, and an optional description. Deactivations count against a limit of four transfers per license per year, and a license cannot be split into smaller pieces.

## OpenMultiSeat status

**➖ Not applicable** — there is nothing to deactivate or transfer. OpenMultiSeat has no license keys, no per-PC activation records, and no transfer-limit accounting, since it is free and open source with no licensing system. See [Activation Dialog](activation-dialog.md).
