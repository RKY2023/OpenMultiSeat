# Activation IDs on this PC

> ASTER reference: https://dokwiki.ibiksoft.com/en/v3/core/gui/gui_mykeys

## What ASTER does

The "Activation IDs on this PC" window shows the Activation ID of the currently installed ASTER copy along with a table of every license that has been activated on the machine. It's opened via the "Activation History on this PC" button on the General Settings tab, and its Save button exports the license list to a text file.

## OpenMultiSeat status

➖ **Not applicable — OpenMultiSeat has no licensing or activation system at all.** There are no license keys, no Activation IDs, no per-seat license limits, and no activation history to display, because OpenMultiSeat is free and open source with no trial period and nothing to activate. This is a deliberate, permanent difference from ASTER, which requires a paid per-seat license after a 14-day trial (see [About OpenMultiSeat](../user-manual/about-openmultiseat.md)). Every seat OpenMultiSeat can technically support is usable from the moment it's installed — there is no concept of a license limiting how many seats can run.

Nothing in the GUI, Service, or Core layers tracks anything resembling a license or activation record, and none is planned; this page intentionally has no OpenMultiSeat equivalent to build toward.
